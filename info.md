## Sobre
-- Api responsável por fazer a busca de empresas por segmento no google maps, ela irá retornar um json com os dados detalhados de consulta

## Dados
-- JSON [Name, Address, Phone, WebSite, Email, Rating, Reviews, Category]

## UseCases
[] ReturnCompanyDetails:
    -- Deve retornar os dados filtrados das empresas
    -- Deve retornar um json único
